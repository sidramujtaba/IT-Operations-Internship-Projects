# 🏦 Oracle Banking Transaction Monitoring System

## 📌 Project Overview

The Oracle Banking Transaction Monitoring System is a database project developed using Oracle SQL and PL/SQL. It simulates a banking environment by managing customers, accounts, branches, transactions, and alerts generated during banking operations.

The project demonstrates database design, relational modeling, PL/SQL programming, triggers, views, sequences, and SQL reporting queries.

---

## 🚀 Features

- Branch Management
- Customer Management
- Account Management
- Transaction Recording
- Alert Monitoring
- High-Value Transaction Detection
- Failed Transaction Monitoring
- Stored Procedures
- Database Triggers
- SQL Views
- Oracle Sequences
